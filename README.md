# Vila Griliya SM - Website Resmi

Website resmi dan landing page reservasi untuk **Vila Griliya SM**, hunian kabin kayu segitiga (A-Frame) yang sejuk dan asri di kaki Gunung Rinjani.

📍 **Lokasi:** Dusun Jorong, Jln. Puri Rinjani, Nusa Tenggara Barat (NTB)  
📱 **Kontak / WhatsApp:** [+62 859-6710-9790](https://wa.me/6285967109790)

## Fitur Website
- **Full Responsive & Modern UI:** Dibuat dengan Tailwind CSS & Lucide Icons mengacu pada desain resort modern.
- **Hero Section:** Dilengkapi headline 2 baris ringkas dengan hook berganti dinamis.
- **Floating Amenities Bar:** Akses cepat ikon fasilitas (Free Wi-Fi, Alat BBQ, Udara Sejuk, Dapur, Parkir, Taman Asri).
- **Featured Rooms:** 3 Kamar Tipe Biasa (mulai Rp 250rb) & 2 Tipe Family Room.
- **Aktivitas & Rekreasi:** Auto-slide carousel dengan preview foto-foto pengalaman menginap.
- **WhatsApp Direct Booking:** Integrasi tombol pemesanan langsung terhubung ke pengelola vila.
